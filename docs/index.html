Built for Performance & Precision

Engineered specifically for low latency and zero desktop disruption

⏱️

Monotonic High-Res Engine

Driven by Win32 QueryPerformanceCounter to prevent wall-clock time drift, DST jumps, or manual system time distortion.

🎨

3 Transparent Overlay Modes

Choose between Minimal typography overlay, Progress bar tracking, or perimeter Edge Border mode that traces your screen boundary.

🌙

Sleep & Resume Recovery

Seamlessly listens to Windows power broadcase messages (WM_POWERBROADCAST) to auto-synchronize timer elapsed state on wake.

🔔

Rich Notification Alerts

Integrates native Windows Notification Toast balloons and customizable WinMM audio chimes upon work session completion.

💾

Settings Persistence

Saves your mode selection, custom durations, and preferences in %APPDATA%\Timer420\timer420.ini cleanly.

🧪

100% Mock-Testable Engine

Includes a fast FakeClock mock suite that verifies state transitions and 2-hour duration cycles in under 1ms.
