# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Timer420 seriously. If you believe you have found a security vulnerability in Timer420, please report it to us responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email or submit a private security advisory on GitHub describing:
1. Type of issue (e.g. buffer overflow, privilege escalation, DLL hijacking)
2. Location in codebase
3. Step-by-step instructions to reproduce
4. Proof-of-concept exploit if available

We will acknowledge receipt of your report within 48 hours and work with you on a resolution.
