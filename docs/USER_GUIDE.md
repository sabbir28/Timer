# Timer420 User Guide

## Basic Controls

Timer420 runs in the background with a transparent overlay and a system tray icon.

### Global Hotkeys
- `Ctrl + Shift + Space`: Show or hide the transparent overlay.
- `Ctrl + Shift + S`: Start or pause the countdown timer.
- `Ctrl + Shift + R`: Reset the timer to full duration.

### System Tray Menu
Right-click the tray icon to access:
- **Preset Durations**: Set 2 Hours, 1 Hour, 30 Minutes, 15 Minutes.
- **Overlay Modes**: Switch between Minimal, Progress, and Edge Border modes.
- **Start / Pause / Reset**: Direct menu controls.
- **Exit**: Close Timer420 cleanly.

## Display Modes

1. **Minimal**: Clean time display with deadline time and break indicator.
2. **Progress**: Minimal layout + horizontal progress bar with percentage readout.
3. **Edge Border**: 6px border tracing the edge of your screen boundary as time elapses.
