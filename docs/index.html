Built for Pure Precision

Zero garbage collection, minimal memory footprint, and low latency

Monotonic Clock

Powered by QueryPerformanceCounter to prevent wall-clock NTP time drift, DST jumps, or manual system clock changes.

3 Overlay Modes

Switch seamlessly between Minimal timer overlay, Progress bar tracking mode, or perimeter Edge Border mode.

Sleep / Resume Sync

Listens to Windows power broadcast messages (WM_POWERBROADCAST) to accurately adjust elapsed duration on system wake.

Native Windows Alerts

Integrates Windows Notification Toast balloons and customizable WinMM audible completion chimes upon timer finish.

INI Persistence

Saves your preferred mode, custom session durations, and hotkey preferences to %APPDATA%\Timer420\timer420.ini.

FakeClock Test Suite

Includes a deterministic clock mock framework capable of advancing multi-hour timer tests in less than 1 millisecond.
